## ✨ Features & Architecture

- 🚪 **Authentic Hand-Drawn Entrance:**
  - Interactive entrance doors with natural wood creak and open sounds.
  - Cheerful avatar standing in the window waving and cycling developer quotes.
  - Hanging mouse doodle swinging gently in the breeze.
  - Smooth zoom-through entrance into the corridor on wheel scroll or drag.

- 🏛️ **Infinite 3D Wooden Corridor:**
  - Authentic lengthwise wood plank textures with anisotropy filtering.
  - Wooden baseboard skirting along hallway walls.
  - Dynamic infinite segment streaming for seamless unbounded forward exploration.
  - Smooth parallax mouse steering (gentle look left/right without jitter).
  - Natural auto-glance math smoothly turning toward doors as you approach them.

- 🚪 **4 Interactive 3D Rooms:**
  1. **Gallery Room (Projects):** Herringbone parquet floor, cityscape backdrop, hanging Polaroid clips with 3D flip card inspections and live project links.
  2. **Studio Room (Skills & Stack):** Architectural grid breakdown of full-stack, AI, and cloud engineering capabilities.
  3. **About Room (Biography):** Personal story, engineering philosophy, and milestones.
  4. **Contact Room (Messenger):** Secure in-browser note sender with rate-limiting, email validation, and honeypot spam protection.

- 🎨 **Visual Themes & Audio:**
  - **Classic Hand-Drawn Sketchbook Mode** (warm parchment paper aesthetic).
  - **Cyan Architectural Blueprint Mode** (inverted deep cobalt grid aesthetic).
  - Sound effects with single-instance AudioContext management.
  - Achievement unlock system tracking user exploration milestones.

## 🛠️ Local Development

```bash
# Clone the repository
git clone https://github.com/stl-sahadat/practic-prottfolio.git
cd practic-prottfolio

# Install dependencies
npm install

# Start local dev server
npm run dev
```

Visit `http://localhost:5174/` to view the 3D portfolio locally.

### Production Build
```bash
npm run build
npm run preview
```

## 🌐 GitHub Pages Live Hosting

The production-ready build is compiled and published directly on the **`gh-pages`** branch.

To enable GitHub Pages:
1. Go to repository **[Settings > Pages](https://github.com/stl-sahadat/practic-prottfolio/settings/pages)**.
2. Under **Build and deployment**:
   - **Source**: Select **Deploy from a branch**
   - **Branch**: Select **`gh-pages`** and folder **`/ (root)`**, then click **Save**.
3. Your 3D Portfolio is live at:
   👉 **[https://stl-sahadat.github.io/practic-prottfolio/](https://stl-sahadat.github.io/practic-prottfolio/)**
